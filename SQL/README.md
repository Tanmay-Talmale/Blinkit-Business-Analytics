# SQL Analysis

This folder contains the complete SQL analysis script for the Blinkit Business Analytics project.

## File

### `blinkit_business_analysis.sql`

This single SQL script contains:

- Database and table setup
- Data import using `LOAD DATA LOCAL INFILE`
- Data validation and preparation
- Business KPI analysis
- Revenue and order analysis
- Customer analysis
- Store performance analysis
- Delivery and operational analysis
- Promotion analysis
- Retention and churn analysis
- 20 business-focused SQL queries

## Tools Used

- MySQL
- SQL
- Window Functions
- CTEs
- Aggregate Functions
- Joins
- Subqueries
