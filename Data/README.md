# 📊 Blinkit Datasets

This folder contains the cleaned Blinkit order-level datasets used for the analysis.

## Files

| File | Description |
|---|---|
| `blinkit_orders_2022_cleaned.csv` | 2022 cleaned order data |
| `blinkit_orders_2023_cleaned.csv` | 2023 cleaned order data |
| `blinkit_orders_2024_cleaned.csv` | 2024 cleaned order data |
| `blinkit_orders_2025_cleaned.csv` | 2025 cleaned order data |
| `blinkit_orders_2026_cleaned.csv` | 2026 partial/YTD order data |

## Data Granularity

Each row represents an individual order.

## Important Note

The 2026 dataset represents partial-year/YTD activity. Therefore, direct full-year comparisons between 2026 and previous years should be avoided unless the comparison period is aligned.
