# Presentation

This folder contains the presentation for the Blinkit Business Analytics project.

## File

### `Blinkit_SQL_Business_Analysis_20_Queries.pptx`

The presentation covers:

- 20 business problems
- SQL-based analysis
- Business-focused solutions
- Key analytical findings
- Business recommendations

## Purpose

The presentation summarizes the SQL analysis in a structured, presentation-ready format and explains how the analysis can support business decision-making.

## Tools Used

- MySQL
- SQL
- Microsoft PowerPoint

> The presentation is based on the SQL business analysis performed on the Blinkit order dataset.
